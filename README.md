# quick-repo-setup
a small project i made that quickly sets up a repo for you.

## How to use it:

1. Make a new folder for your repo.
2. Save the script as setup.sh (or setup.bat if you're on Windows).
3. Run it.
4. It creates a src, assets, docs, and tests folder, plus a generic README.md and .gitignore.
5. Delete the setup script afterwards if you want, or keep it for next time.

It's simple and does the boring stuff automatically.
